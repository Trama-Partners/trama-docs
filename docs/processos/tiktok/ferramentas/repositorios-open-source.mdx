# Projetos open-source e APIs

Para quem quer construir a própria ferramenta em vez de assinar uma plataforma. Todos os links
abaixo são repositórios oficiais confirmados.

## APIs e captura de dados

| Projeto | O que faz | Link |
| :--- | :--- | :--- |
| **tiktok-live-python** | API em Python para receber dados em tempo real: chat, presentes, visualizações | `https://github.com/tiktool/tiktok-live-python` |
| **TikTok Live Spy** | Captura em tempo real chat, presentes e interações de qualquer sala pública | `https://github.com/QingMXL/tiktok_live_spy` |
| **PeterSvP's TikTokLiveTool** | Ferramenta GUI que processa e categoriza dados da live em tempo real | `https://github.com/petersvp/TikTokLiveTool` |
| **wshook-extension** | Extensão de navegador que intercepta mensagens da live e envia para um webhook | `https://github.com/nglmercer/wshook-extension` |

## Overlays e integração com OBS

| Projeto | O que faz | Link |
| :--- | :--- | :--- |
| **TikTok Streaming Toolkit** | Projeto Node.js para criar widgets de notificação (presentes, seguidores) no OBS | `https://github.com/alexlobaza/TikTokStreamingKit` |
| **tiktok-live-overlay** | Overlay compacto para OBS Studio com análises em tempo real | `https://github.com/sa3oodi/tiktok-live-overlay` |
| **live-avatars** | Avatares animados que reagem à live — comentários viram balões | `https://github.com/matheusmonck/live-avatars` |

## Utilitários

| Projeto | O que faz | Link |
| :--- | :--- | :--- |
| **ttytok** | Assiste lives do TikTok direto no terminal (CLI) | `https://github.com/PirateTok/ttytok` |
| **TikTok-Live-Liker** | Userscript para curtir automaticamente lives do TikTok | `https://github.com/AmpedWasTaken/TikTok-Live-Liker` |

## Por perfil de uso

- **Criador buscando automação total** → invista nas
  [plataformas pagas](./extensoes-de-navegador.mdx).
- **Streamer que usa OBS** → **TikTok Streaming Toolkit** ou **tiktok-live-overlay**.
- **Desenvolvedor** → APIs em Python ou Node.js para bots de moderação, sistemas de análise ou
  integrações próprias.

:::warning[Automação e política]
Curtidas automáticas e inflação artificial de engajamento são explicitamente proibidas pelo
TikTok Shop — ver
[Produtos e conteúdo proibido](../conformidade/produtos-e-conteudo-proibido.mdx). Ferramentas de
leitura de dados (chat, presentes, GMV) são bem menos arriscadas que ferramentas de escrita.
:::
