# Extensões de Chrome para live no TikTok Shop

Extensões disponíveis na **Chrome Web Store**. Nenhuma tem link direto fixo (ID) publicado — para
instalar, pesquise pelo nome exato na
[Chrome Web Store](https://chromewebstore.google.com/).

| Extensão | O que faz | Busca |
| :--- | :--- | :--- |
| **Loops Live** | Câmera e microfone virtuais, ordem aleatória, picotagem de áudio, cronômetro, banner, proteção contra violação e múltiplas contas. É a extensão usada no [método de câmera virtual](../lives/transmissao-camera-virtual.mdx) | Link e cupom na descrição dos vídeos do autor |
| **Criatik Live** | Controle geral da live no TikTok Shop (ativada por chave de acesso) | "Criatik Live" |
| **Live Guard Pro** | Proteção contra violações, oferta relâmpago automática e timer de encerramento | "Live Guard Pro" |
| **TKS PRO — Assistente de LIVE** | Fixação automática de produto, alerta sonoro de vendas, painel GMV e moderação de chat | "TKS PRO" |
| **Live Moderador Pro** | Controla a live, fixa produtos e oferece moderador com IA para o chat | "Live Moderador Pro" |
| **TikTok Live — Encerrar Automático** | Programa o encerramento automático da transmissão | "TikTok Live Encerrar" |
| **Live Pin** | Refixa automaticamente o banner do produto a cada 50 segundos | "Live Pin" |
| **ShopCare** | Encerra a live e gerencia avaliações de produtos pela interface | "ShopCare" |
| **TikCroo: Extension** | Ponte de integração entre a live do TikTok e o OBS Studio (alertas e transições) | "TikCroo" |

## Como escolher

| Necessidade | Extensões indicadas |
|---|---|
| Rodar live de IA com câmera virtual | **Loops Live** |
| Só evitar violação | **Live Guard Pro**, **Live Moderador Pro** |
| Fixação e banner de produto | **Live Pin**, **TKS PRO** |
| Métricas e GMV na tela | **TKS PRO** |
| Encerramento programado | **TikTok Live — Encerrar Automático** |
| Integrar com OBS (alertas, widgets) | **TikCroo** + [repositórios open-source](./repositorios-open-source.mdx) |

Para as plataformas pagas completas (Live Loop, Loopyz, Infinity Live), ver o
[comparativo de plataformas](./plataformas-de-live-comparativo.mdx).

:::warning Cuidado com extensões de terceiros
Extensões de gerenciamento de live pedem acesso à sessão logada do TikTok Shop. Instale apenas
o que você conseguir avaliar, e prefira uma conta de operação separada da conta principal.
:::
