# IAs de texto e bancos de prompt

Todo fluxo de criativo deste hub começa em texto: o prompt da imagem base, os prompts JSON de
animação e o roteiro de narração. Esta página lista **onde gerar esse texto** e **onde pegar
prompt já escrito por outra pessoa**.

## Modelos de linguagem

| Ferramenta | Link | Papel aqui |
| :--- | :--- | :--- |
| **ChatGPT** | `https://chatgpt.com/` | É o modelo usado nas fontes: compõe produto + referência numa imagem só, escreve o prompt POV de até 900 caracteres, gera os prompts JSON de animação e o roteiro de narração de 1.000 caracteres |
| **Gemini** | `https://gemini.google.com/app` | Mesma conta Google do Flow e do Labs. Além de texto, anima imagem — ver [Geradores de vídeo e imagem](./geradores-de-video-e-imagem.mdx) |
| **DeepSeek** | `https://chat.deepseek.com/` | Modelo de raciocínio gratuito. Foi a IA usada nas duas pesquisas que originaram as páginas de ferramentas deste hub |
| **Qwen** | `https://chat.qwen.ai/` | Modelo da Alibaba, gratuito |
| **Kimi** | `https://kimi.com/` | Modelo da Moonshot AI, forte em texto longo — útil para lote de roteiros de uma vez |
| **Meta AI** | `https://www.meta.ai/` | Chat da Meta e porta de entrada do **Vibes**, o feed/gerador de vídeo por IA da casa |

Nenhum é obrigatório: o prompt é texto, e qualquer um dos seis escreve. O motivo prático de ter
mais de um é o **limite diário da conta gratuita** — quando um trava, você troca de aba em vez de
parar a produção.

## Bancos de prompt pronto

Alternativa a escrever prompt do zero. Todos são focados em UGC e TikTok Shop brasileiro.

| Fonte | O que entrega | Custo |
| :--- | :--- | :--- |
| **Hauntr.AI** (`https://hauntr.com.br/`) | Plataforma brasileira fechada: biblioteca de prompts validados em operação real, agente que escreve o prompt a partir da descrição do produto, estúdio de imagem/vídeo UGC/voz/legenda/upscale 4K, painel de faturamento multi-conta e a ferramenta **GURU**, que analisa vídeo viralizado para replicar a estratégia | R$ 67/mês (1.000 créditos) a R$ 297/mês (4.400 créditos) |
| **Higor [PROMPTS]** (`https://t.me/higorprompts`) | Canal de Telegram com mais de 6 mil membros: prompts para influencer de IA e TikTok Shop | Grátis |
| **Nespol — movimentos realistas em UGC** (`https://nespol.com.br/blog/prompts-gratis-movimentos-realistas-em-influencers-ugc-feitas-com-ia/`) | Artigo com 5 prompts prontos: foto de perfil da influenciadora, puxar a alça da roupa, apontar para baixo (CTA), balançar o cabelo e girar 45° para try-on. Escritos para Flow com Nano Banana e para o Gemini, com GIF de exemplo de cada movimento | Grátis |

:::warning[Prompt de influencer não é o formato POV do hub]
Os bancos acima geram **pessoa em cena** (influencer UGC). Os métodos documentados em
[Vídeo POV com Google Flow](../criativos/video-ia-no-desktop.mdx) e
[Produção dos ativos](../lives/producao-dos-ativos.mdx) fazem o oposto — só mãos e produto,
justamente para o modelo não errar rosto. Use os dois caminhos com consciência: pessoa gerada
por IA aumenta a chance de o vídeo ser lido como conteúdo sintético.
:::

## Como escolher

| Necessidade | Onde ir |
| :--- | :--- |
| Escrever prompt de imagem, prompt JSON de animação ou roteiro de narração | **ChatGPT** |
| Estourou o limite gratuito no meio da produção | **Gemini**, **DeepSeek**, **Qwen**, **Kimi** ou **Meta AI** |
| Pesquisar ferramenta ou política e sair com texto organizado | **DeepSeek** |
| Não quer escrever prompt — quer copiar o que já funcionou | **Higor [PROMPTS]** (grátis) ou **Nespol** (grátis) |
| Quer prompt validado + estúdio + painel multi-conta num lugar só | **Hauntr.AI** (pago) |

:::note[Data da coleta]
Preços e recursos conferidos nas páginas oficiais em **agosto de 2026**. Planos de IA mudam com
frequência — confirme antes de assinar.
:::
