# Consultoria — mapa da área

Metodologias de diagnóstico e otimização que o time entrega aos clientes. Cada uma é um processo
fechado: parte de um dado que o cliente já tem, prioriza onde mexer, executa e mede.

## Trilha

| # | Área | Você sai sabendo |
|---|---|---|
| 1 | [SEO](./seo/quick-wins-search-console.mdx) | Achar as palavras em que o site já está na faixa 8–20 e subir de posição otimizando a página que já ranqueia |

- **Cliente quer resultado rápido em busca orgânica** → [Quick wins com Search Console + IA](./seo/quick-wins-search-console.mdx).
- **Preciso saber que ferramenta usar em cada etapa** → [Catálogo de ferramentas](../shared/ferramentas/catalogo.mdx).

## Como as metodologias são escritas

Toda página de metodologia segue a mesma anatomia, para o consultor conseguir executar sem ler o
documento inteiro antes:

| Seção | Serve para |
|---|---|
| **Ferramentas** | Saber o que precisa ter em mãos antes de começar |
| **Passo a passo** | Executar |
| **Regras que importam** | Decidir nos pontos em que o passo a passo abre escolha |
| **Pontos de atenção** | Não errar onde os outros erram |
| **Checklist** | Conferir a entrega antes de fechar |

:::note[Área em construção]
Hoje só a metodologia de SEO está documentada. Análise de dados e growth entram como áreas
próprias quando o material existir — a numeração das áreas acompanha a ordem em que uma
consultoria costuma usá-las.
:::
